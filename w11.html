Retrieval-Augmented Generation

How do you make a language model answer from documents it never saw?

Everything for today is on this page: the video parts, the checkpoint forms you answer in class, and what comes after. Use the same address during class and afterwards.

RAG does not make a model smarter. It changes what the model is allowed to read before it answers.

RETRIEVE

Find the passages that can answer the question.

GENERATE

Answer from those passages only, and cite them.

EVALUATE

Measure retrieval and generation separately, so you know what failed.
